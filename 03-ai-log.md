## Những nội dung AI đã hỗ trợ

- Đọc hướng dẫn lab, làm rõ các file cần nộp và cách tổ chức branch cá nhân, branch nhóm.
- Từ danh sách problem tôi cung cấp, hỗ trợ viết Problem Scan và chọn 3 bài toán để làm Quick Problem Cards.
- Hỗ trợ chỉnh sửa Deep-Dive Report cho bài toán phân loại feedback bệnh nhân Vinmec; đề xuất metric, phạm vi, HITL, fallback và ghi rõ các số liệu giả định.
- Trình bày Current-State và Future-State Workflow bằng khối ký tự theo mô tả tổng quan và ý tưởng cung cấp, thể hiện handoff, thời gian và bottleneck; xuất thêm sơ đồ PNG.
- Viết prompt_prototype.py với system prompt, JSON output và adversarial tests; đối chiếu tài liệu SDK chính thức và chạy kiểm tra logic cục bộ.
